## Smart Expense Tracker

A simple and professional Expense Splitter / Tracker web application built using HTML, CSS, and JavaScript.  
Track group expenses, see who owes money, and manage shared spending easily.

---

# Features

- Add multiple people dynamically  
- Add expenses with payer information  
- Delete individual expenses  
- Clear All: resets people, expenses, and summary  
- Automatic summary calculation  
  - Green → person receives money  
  - Red → person owes money  
- Summary only appears after first expense 
- Data persists in localStorage
- Responsive & clean UI

---

# *How It Works*

1. Add participants (people) to the group  
2. Add expenses and select who paid  
3. The total expense is split equally among all people  
4. The payer gets credited, others are debited  
5. Summary shows who owes or receives money  
6. Click Clear All to reset the app completely  

---

# *Technologies Used*

- *HTML5* – structure  
- *CSS3* – styling, responsive design  
- *JavaScript* – DOM manipulation, event handling  
- *localStorage* – data persistence
